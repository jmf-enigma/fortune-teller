# Fortune Teller

## 把复杂命盘，讲成你真正看得懂的人生分析

[![CI](https://github.com/jmf-enigma/fortune-teller/actions/workflows/ci.yml/badge.svg)](https://github.com/jmf-enigma/fortune-teller/actions/workflows/ci.yml)

[English](README.en.md) · [完整能力](docs/SCOPE.md) · [准确性边界](references/accuracy-evaluation.md)

Fortune Teller 是一款运行在 Codex 和其他 Agent 中的本地命理 Skill。

你不需要懂十神、宫位、星曜或卦理。只要告诉它你想看什么，它会一步步问完必要资料，然后先用普通话讲清结论：你的人生主线是什么、事业和财运更适合从哪里发力、目前处在什么阶段，或者眼前这件事有哪些机会与风险。

> **你只管说问题，排盘、核对和术语翻译交给它。**

~~~text
用 $fortune-teller 看我的八字人生总览，重点讲事业和财运。
~~~

当前版本：0.6.0 · [GitHub 仓库](https://github.com/jmf-enigma/fortune-teller)

## 你可以用它做什么

| 人生总览 | 单项深看 | 当前问题 |
|---|---|---|
| 看人生主线、事业、财富、关系与重要阶段 | 只看事业、财运、感情或身心节奏 | 看一个选择、机会、关系进展或当下困惑 |
| 适合八字、紫微和西洋本命盘 | 先聚焦你最关心的领域，不塞无关内容 | 适合塔罗、周易三钱或梅花两数 |

你可以直接这样说：

~~~text
我想看人生整体，重点看事业和财运。
我最近适不适合换工作？先帮我把问题问清楚。
我想看未来一年的事业重点，不要先讲术语。
帮我看这段长期关系里最需要注意什么。
~~~

## 用起来很简单

### 1. 说出你最关心的事

不用先选流派，也不用填写一大张参数表。你可以从“人生整体”“只看一个方面”或“当前一件事”开始。

### 2. 回答几个必要问题

出生盘通常会询问出生日期、时间和地点；涉及阶段时，再询问想看的日期。中国大陆可以直接填“北京”“上海”或“中国大陆”，香港可以直接填“香港”。不知道出生时间也可以如实说，它会自动缩小结论范围，不会替你猜。

### 3. 核对后开始

正式计算前会显示本次资料和查看范围。填错了可以修改，不想继续可以取消。

### 4. 第一屏直接看结果

结果先按你关心的主题展开，专业术语统一放在后面的“专业依据（高级）”里。

~~~text
事业
你的事业主线是把想法做成作品、方案或可交付成果。
比起只等待机会，更适合用看得见的成果证明价值。

财富
财富重点是把成果转成实际回报，同时说清合作中的归属、分成和责任。
有机会不等于一定进财，真正要看成果能否稳定兑现。

当前阶段
眼下更值得投入的是完成作品、承担职责和补足方法能力。
这是阶段重心，不等于一定升职或收入一定增加。
~~~

上面只是输出风格示例，不是对所有人的固定判断。

## 为什么它不只是“套话生成器”

- **先计算，再解释。** 八字、紫微和西洋占星由固定版本的本地程序排盘；塔罗与周易保留本次抽取或起卦结果。模型不凭感觉手算一张盘。
- **先回答，再讲术语。** 普通结果优先回答事业、财富、关系和当前阶段；十神、星曜、宫位、相位与规则来源需要时再展开。
- **资料不够就少说。** 时辰未知、坐标缺失、流派分歧或规则尚未闭合时，会明确停在哪里，不把候选说成定论。
- **同一个问题不反复换答案。** 后续追问沿用同一份结果；换问题、改关键资料或重新抽取时，会明确开始新一轮。
- **结论可以回头核对。** 专业模式会展示本次盘面依据、支持因素、反例和什么情况会让判断改变。

## 支持的方法

| 方法 | 适合看什么 |
|---|---|
| **四柱八字** | 人生整体、事业学习、财富资源、长期关系，以及原局—大运—流年的阶段变化 |
| **紫微斗数** | 人生主题、事业、财富、关系、身心节奏，以及本命—大限—流年的变化 |
| **西洋本命盘** | 性格与人生主题、事业、关系、资源及其他本命领域 |
| **塔罗** | 当前问题、不同选择、支持因素、风险和下一步行动 |
| **周易三钱** | 当前处境、变化过程与行动反思 |
| **梅花两数** | 固定两数起卦下的体用、互卦和变化关系 |

当前八字发布范围只接受出生时实际 UTC 偏移为 +08:00 的资料；西洋占星目前只做本命盘，不含行运；梅花两数仍是预览功能。六爻、奇门和吠陀占星尚未开放。详细边界见 [完整方法范围](docs/SCOPE.md)。

## 准确性：它认真解决什么，不假装解决什么

Fortune Teller 会尽量减少几类真实而常见的错误：排错盘、混用时间口径、资料不足时硬猜、只挑支持结论的证据，以及把传统术语直接包装成具体事件。

它不能证明命理或占卜具有科学意义上的预测准确率，也不会承诺升职、发财、结婚、分手或其他具体结果。这里的“更准”首先指：

- 盘面按声明的规则算对；
- 解读能回到本次盘面、牌面或卦面；
- 分歧和不确定性不会被藏起来；
- 输出尽量具体，但不把传统判断说成必然事实。

如果要认真检验一次判断，可以提前写下结论、时间窗口和正反标准，再用未来记录核对。方法见 [准确性评估](references/accuracy-evaluation.md)。

## 隐私优先

- 排盘、起卦和抽取在本地完成，项目源代码不会主动发送网络请求；
- 默认不把你的输入写入文件；
- 安装依赖时需要访问 npm，终端或宿主软件也可能保留屏幕记录；
- 不要把真实生辰、精确位置、私人问题或回放凭据提交到 GitHub issue、源码或公开截图。

## 开始使用

### 已经安装为 Agent Skill

直接在对话中输入：

~~~text
$fortune-teller 我想看八字人生总览，请一步一步问我，重点看事业和财运。
~~~

### 在本地运行

需要 Node.js 20 或更新版本。在项目目录中运行：

~~~bash
npm ci --ignore-scripts
npm start
~~~

npm start 会打开中文交互界面。

### 安装为 Codex Skill

~~~bash
cd /absolute/path/to/fortune-teller
npm ci --ignore-scripts
ln -s /absolute/path/to/fortune-teller ~/.codex/skills/fortune-teller
~~~

刷新宿主后即可调用 $fortune-teller。压缩包不包含 node_modules，首次使用需要在解压目录安装锁定依赖；Agent 不应在没有许可时自行联网安装。

## 一般模型够用吗？

够用。一般模型可以完成资料收集、本地计算、单体系标准解读，以及事业、财富、关系或当前问题的聚焦分析。

Pro 更适合长篇综合、多体系交叉比较、流派分歧审计和逐条来源核对。两者使用同一份本地盘面；Pro 不会改变排盘，也不会让未经科学验证的传统预测自动变得更准确。详见 [模型层级](references/model-tiers.md)。

## 安全边界

请把它当作传统文化解读与自我反思工具，不要用它诊断疾病、判断怀孕、预测死亡、认定犯罪、裁决关系忠诚、指导投资或法律行动，或验证被害妄想。重要决定仍应依据现实资料和专业意见。
