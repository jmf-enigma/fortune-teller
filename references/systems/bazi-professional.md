# 八字专业裁决 v0.6

本文件描述 `src/core/bazi-adjudicator.mjs`。它只解释当前引擎能重放的排盘事实和已登记路线，不把传统方法包装成科学预测，也不从用户经历倒推时辰、旺衰、格局或用神。

## 用户先看到什么

普通结果顺序固定为：

1. `conclusion`：当前最重要的路线状态；
2. `plain_language`：不依赖术语的解释；
3. `change_conditions`：什么新事实会改判；
4. `reality_checks`：可以支持或反驳这条解释的连续现实记录；
5. 用户要求时再看旺衰候选、成败救应路线、调候/通关和阶段重判证据。

哈希、规则包 ID 和 fact ID 都留在高级依据，不作为准确性卖点。

## 调用

```js
import { calculate, adjudicate, adjudicateBazi } from "../../src/index.mjs";

const calculation = calculate("bazi", {
  date: "2000-08-16",
  time: "04:00",
  timezone: "Asia/Shanghai",
  chart_sex: "male",
  target_date: "2026-08-24",
});

const result = adjudicateBazi(calculation);
// 或 adjudicate(calculation)

const career = adjudicate(calculation, { topic: "career_study" });
const wealth = adjudicate(calculation, { topic: "wealth_resources" });
const relationships = adjudicate(calculation, { topic: "relationships" });
```

CLI 可用通用 `adjudicate`；`adjudicate-bazi` 保留为兼容入口。两者都只读取一份已计算的 envelope。

这里的机械裁决报告与通用 reading artifact 是两个合同。普通结果可以直接展示 `adjudicateBazi` 的输出；如果另行构造证据绑定 reading，仍须服从 `rule-registry` 和 `reading-validator` 的认识上限，不能把裁决器之外的自由改写称为已机器证明。

三条专题路线只组织已计算事实：事业学习看职责、学习支持、成果输出；财富资源看资源、产出转化、共同资源边界；长期关系以日支及其合冲刑害等关系为主。透干与藏干分开；两个轴同时出现只叫“同见”，不叫闭合链。岁运只可强调原局已有轴，新增十神单列。关系阶段先读岁运与日支的精确关系，男财／女官杀只在用户显式选择传统二元参数后作为流派性补充，不能描述伴侣或预测结果。

## 固定分析次序

```text
排盘重放
  -> 季节、月支和月令人元候选
  -> 根位、透出、可见生扶/克泄耗
  -> 并列旺衰假设
  -> 月令格局复合成格路线
  -> 同一路线的受损、破格、配对救应
  -> 扶抑 / 调候 / 通关 / 病药并列
  -> 原局
  -> 原局 + 当前大运完整重判
  -> 原局 + 当前大运 + 流年完整重判
```

不同视角不平均、不投票，也不合成一个伪精确“综合用神”。

## 月令与根位证据

`facts.structure.month_context` 记录季节和月支；`month_command` 记录该月支的藏干候选。当前没有安装日内人元司令分日表，所以裁决器会明确写“候选”，不会假定当天一定由某一藏干司权。

根位按真实位置记录：

- 哪一柱地支；
- 同干还是同五行；
- 本气、中气或余气；
- 对应的柱/藏干 fact ID。

这比“出现几个同类元素”更具体，但仍不等于完成强弱轻重。距离、月令实际司权、刑冲后根气是否可用、透干真假和制化顺序尚未形成完整状态机。

## 旺衰：竞争假设而非分数

裁决器固定保留偏强和偏弱两个候选，各自列支持、反证和改判条件。它不设置藏干权重、百分比或分数阈值，也不从“五行缺什么”直接取用神。

月令、根位和可见生扶支持承载；可见克、泄、耗构成压力。两边都存在时结果保持并列或未决。只有登记条件足够区分时，扶抑才给出相应方向。

## 格局成败与病药救应

月令十神只是候选。状态机固定为：

```text
候选
  -> 命中完整登记成格路线：成立
  -> 同一路线命中损害：受损
  -> 损害路线闭合、无匹配救应：破格
  -> 同一病点的登记救应也闭合：救应
```

每条路线保留 `state_history`。救应不会抹掉受损曾经发生；单独出现一颗“救应十神”也不会越过对应病点。

当前规则包扩展到正官、七杀、财、印、偏印、食神、伤官和建禄/月劫等月令候选的有界复合路线。凡是取决于相对轻重、精确位置、先后制化、合而真化、墓库或空亡的条件，继续标为 `screening_only` 或未决。路线覆盖增加不等于完整《子平真诠》格局全集。

## 调候：120 条原文提及干筛查入口

`bazi-climate-rulepack.mjs` 固定 10 个日干 × 12 个太阳月支，共 120 个入口。每项只包含：

- 日干、月支；
- 在对应原文范围内提及的天干；数组位置不代表优先次序；
- 章节级来源定位；
- 已独立核对的少量角色示例，以及缺少节气段/条件闭合时必须未决的限制。

裁决器对每个提及干报告：

- `visible`：出现在四柱天干；
- `hidden`：只见于地支藏干，并保留具体根位；
- `absent`：当前盘面没有。

这不等于调候已经成功，也不等于该五行会带来某类事件。乙午、乙酉、癸辰、癸未、壬丑五项需要当前缺失的月内节气段；其他多项也含主用、并用、佐用、条件救应、自带或反忌角色。未逐条闭合前一律不排固定先后。120 是来源筛查覆盖，不是完整调候语料库。

## 通关：可重放候选，不宣称有效

通关只在以下三项都可重放时出现候选：

1. 两个可见五行构成登记控制关系；
2. 它们分别有明确的天干事实；
3. 固定的相生中介元素在盘中可见。

输出说明“存在通关候选”，同时保留相战两端和中介证据。它不会断言两端都达到足以称“战”的强度，也不会断言中介得令、有根、位置妥贴或真的有效。

## 干支关系与刑的边界

引擎区分天干重复、五合、冲和克；地支重复、六合、冲、害、破、刑、三合和三会。

特别是：

- 只见寅巳、巳申或寅申之一时，标为“寅巳申三刑的两支组件”，不说完整三刑；
- 只见丑戌、戌未或丑未之一时，同样只作两支组件；
- 子卯是完整两支关系；
- 寅巳申或丑戌未三支齐全时另发完整三刑事实；
- 大运或流年可以补齐第三支，但“补齐关系”仍不是具体事故、疾病、官非或婚变。

## 原局—大运—流年：完整登记路线重判

在明确出生时刻、显式 `chart_sex` 和 `target_date` 时，引擎给出当前大运与立春年界。裁决器不再只看“三层是否结构相连”，而是形成三份输入：

1. natal：冻结原局；
2. decadal：原局加入当前大运干支；
3. yearly：上一层再加入流年干支。

每一层都重新执行全部已登记成格、受损和配对救应 predicate，并报告：

- 当前路线状态；
- 相对上一层新开启或关闭的条件；
- 哪一层只增加候选而未闭合；
- 边界不可判时为何停止。

原局判断永不因后来的运年而被改写。大运是阶段环境，流年是较短触发；二者可以使一条登记路线在该层满足或失去条件，但不能直接命名升职、发财、结婚、疾病、事故等事件。目标日碰起运或立春边界且存在候选时，阶段保持不可用。

## 五个视角的关系

- **格局**：只服务于月令复合路线及其成败救应；
- **扶抑**：只有竞争旺衰足够区分时才给方向；
- **调候**：报告 120 基础条目的用干可见性，不覆盖格局或扶抑；
- **通关**：只报告已重放的控制对和中介候选，不保证有效；
- **病药**：先指明已登记病点，再寻找同一路线救应。

方向相同可以记录交集；不同只表示视角不同。只有规则明确登记为互斥时才叫冲突。

## 来源边界

- `lunar-typescript@1.8.6`：排盘字段实现来源；
- 《三命通会》：四柱、十神与干支关系术语范围；
- 《子平真诠》扫描本：月令格局成败救应与行运方法锚点；
- 《滴天髓》：关系性旺衰、体用、月令、通关与命运岁层次方法锚点；
- 《穷通宝鉴》Wikisource：120 条日干×月支原文提及干的条目级定位；数组不表示优先次序，月内节气分段与未闭合角色必须保持未决。

“来源已核对”只说明书目身份、条目范围和本地规则的出处边界。它不证明传统规则真实预测人生。

## 现实核对

- 冻结原句后再观察，不按已知经历改规则；
- 同时记录支持、反驳和说不清的实例；
- 用多个相似周期而不是一次特别相似的回忆；
- 若相反路线都得到材料支持，保持未决；
- 只有出生资料、排盘口径或登记规则前提可证实改变时才重开裁决。

## 仍未闭合

- 人元司令分日和可审计的相对轻重；
- 完整透干通根远近、真假、合化、制化、墓库和空亡状态机；
- 专旺、从势、从财、从杀、从儿、化气等特殊格局；
- 调候条目的全部节气分段、组合和例外语料；
- 通关中介的强度、位置和有效性；
- 六亲及人生领域的有来源、可反驳事件映射；
- 独立命理师对固定规则包的盲审和现实预测效度研究。

这些空白只能靠新增精确事实、固定规则、来源复核和反例测试关闭，不能靠多写术语补齐。
